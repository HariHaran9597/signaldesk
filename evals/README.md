# AI quality evaluation set

`v1.jsonl` is a versioned, synthetic 20-case acceptance set for the evidence workflow. Each row records a source scenario, the minimum safe disposition, required content, and prohibited claims. Cases cover primary announcements, vendor benchmarks, weak or stale evidence, conflicts, duplicate handling, pre-releases, missing licenses, corrections, X-only claims, and prompt injection inside source text.

Run it with `uv run python -m backend.evaluate` (up to 20 model calls) or `--limit 1` for a small run. The command uses the configured Experiential free-only lane, refuses paid fallback, records the fixture hash, prompt version, outputs, and usage in `evals/runs/`, and stops when the provider cannot confirm free zero-cost use. Do not commit run reports; they are ignored.

The current rubric measures disposition accuracy, literal required-phrase coverage, and exact prohibited-phrase matches. A 20-case run on 18 October 2026 with `deepseek/deepseek-v4.1-flash-1017:free` scored all dispositions correctly, covered 45% of required phrases literally, and matched one prohibited phrase in the prompt-injection case. That match was a false positive: the briefing quoted the hostile text to explain it was untrusted. Phrase checks do not establish semantic factuality, citation correctness, or prompt-injection resistance. Treat this as a smoke evaluation, inspect every output, and add reviewed expected evidence IDs and paraphrase-aware criteria before comparing models or claiming quality. A correct refusal should not count as a failure when evidence is missing.
