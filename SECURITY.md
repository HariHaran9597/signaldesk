# Security policy

The public demo is a static, read-only site. Its snapshot contains bounded publisher excerpts, source links, public model-card metadata, and aggregate download observations. It does not include user-submitted X text, generated drafts, model traces, API credentials, or write endpoints.

Please report security issues through GitHub's private vulnerability reporting for this repository when available. Do not post credentials or exploitable details in public issues. Local `.env` files and database files must stay out of commits.

The full API and Compose stack are intended for local use only until authentication, authorization, rate limits, production database controls, backups, and public-hosting review are complete.
